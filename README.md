# Lavagna Tattica Calcio

App web per disegnare schemi tattici di calcio: campo da gioco, giocatori delle due squadre e palla posizionabili liberamente, freccette per corse/passaggi/dribbling e animazione dei movimenti.

## Funzionalità

- Formazioni preimpostate (4-4-2, 4-3-3, 3-5-2) per entrambe le squadre
- Trascinamento di giocatori e palla sul campo
- Disegno di freccette (corsa, passaggio, dribbling) associate a un giocatore o alla palla
- Riproduzione dell'animazione dei movimenti disegnati
- Annulla ultima azione, pulizia freccette, reset formazione
- Salvataggio e caricamento schemi (in locale, nel browser)

## Sviluppo

```bash
npm install
npm run dev
```

## Build di produzione

```bash
npm run build
```
